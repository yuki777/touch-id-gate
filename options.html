URL Gate

対象 URL

ここに書いた URL を開く前に、Touch ID を求めます。保存にも Touch ID が必要です。

行の種類

  • example.com/admin: ページを開く操作（画面の遷移と iframe の読み込み）を止めます。
  • all:api.example.com/token: 行頭に all:（すべての通信）を付けると、ページを開く操作に加えて、ページの中からの通信（スクリプトの fetch など）も止めます。Touch ID を通したタブからだけ通信できます。
  • !example.com/admin/help: 行頭に ! を付けると例外です。対象 URL のうち、このページだけは Touch ID なしで開けます。
  • # で始まる行はコメントです。

URL の書き方

  • スキームは省けます。http と https の両方が対象です。
  • ホストの * はホスト名の一部に一致します（*.example.com は example.com にも一致します）。
  • パスは前方一致です。パスの * は任意の文字列に一致します。パスを省くと、そのホストのすべてのページが対象です。
  • 例外（!）だけは完全一致で、# 以降も書けます。まとめて外すときは * を使います。
